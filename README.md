# BULK ONE

Notionの「画面一覧・画面遷移」と19個の子ページをもとにした、Expo SDK 58 / Expo RouterのモバイルUIです。

## 起動

Node.js 22.13以上（対応LTS推奨）が必要です。標準のNode.js 20ではSDK 58の一部ツールが動作しません。

```sh
npm install
npm start
# Webで確認する場合
npm run web
```

「はじめる」からメールアドレスの形式を満たすデモ値を入力し、確認コード `123456` と8文字以上のデモパスワードで進めます。実際のメールやパスワードは不要です。

| S-030     | 記録メニュー                                         | `/records`                           |
| S-031     | 運動の実施・変更・スキップ・セット・確認・保存       | `/workouts/log`                      |

通常利用はホーム・運動・食事・進捗・設定の5タブです。初回設定はプロフィール→目標→条件→生成→プレビュー→明示的承認の順に進みます。認証前、プラン未承認ではメイン画面にアクセスできません。

子ページ本文の修正済み仕様を優先しています。S-010の目標入力はS-011に集約し、S-030は記録メニュー、S-031は運動記録としました。水分・睡眠・写真解析などの将来機能は準備中です。

## デモの範囲

- 認証、メール送信、Cognito、AI/Bedrock、バックエンドAPIは未接続です。
- プランとレビュー文章は固定のUIサンプルです。実データに基づくAI提案とは表示を分けています。
- 記録の追加・編集・削除・集計と入力途中の保持はメモリ内で動作します。再起動・リロードで消えます。
- 未入力の任意栄養値や体脂肪率は未記録として扱います。未記録日を0として平均しません。
- プラン承認時の設定はスナップショットとして保持し、その後の設定編集で上書きされません。
- ヘルスケアの全ステップはUIプレビューです。OS権限、同期、実データ取得は行いません。Androidは正式仕様どおりHealth Connect表記です。
- 記録削除・退会はデモ内の状態だけをリセットします。本番の削除完了を示すものではありません。
- モック内の写真やキャラクターは権利・元画像が未確定のため、共通アイコンを使っています。

## 検証

```sh
npm run typecheck
npm run lint
npx expo export --platform web
npm run test:e2e
```

E2EはWebビルドを静的プレビューし、EdgeのiPhoneサイズで初回設定・記録・レビューなどを検証します。Microsoft Edgeが必要です。実機のiOS/Android、OS権限や本番API接続の検証は別途必要です。
